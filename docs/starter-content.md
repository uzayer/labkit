# Seed the Database and Edit the Homepage

Tip: We’ve included starter content for new users. It seeds the database with some pre-built pages and collections.

## Seed the database
1. Access the admin panel at http://localhost:3000/admin.
2. If you haven’t already, click `Seed DB` in the admin UI to create new starter content.

## Edit the homepage
Log in again with the admin user you created in the getting-started guide.
