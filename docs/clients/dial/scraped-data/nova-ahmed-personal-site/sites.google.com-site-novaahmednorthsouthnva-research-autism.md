# Shondhi

This is a project that supports children with Autism. Initially, the project targetted locally designed contents for children with autism. Later, we engaged in addressing the challenges caregivers of children with autism face and have developed an application for it named Shondhi.

Anik Shaha, Anik Sinha and Ifti Azad Abeer have worked with me in this project that started as a class project. Now the team is getting bigger!
