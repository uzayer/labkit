# DIAL public-site crawl, 2026-09-12

The two capture directories here are the raw Firecrawl Markdown capture from
2026-09-12. It preserves rendered page text and inline source image URLs; it
does not download, alter, or re-host those images. It replaced an earlier
capture of the same routes and is tracked in this directory as source
evidence.

## Coverage

- **NSUHCI / DIAL** — `nsu-hci-current-website/`: eight routes — `home`,
  `dial-research`, `people`, `publications`, `awards`, `events`,
  `research-collaboration`, `contact-us`.
- **Dr. Nova Ahmed** — `nova-ahmed-personal-site/`: 19 routes — `home` (site
  root) and `home-alias` (the `/home` route), `awards`, `collaborations`,
  `home-contact`, `home-hobby`, `home-news`, `home-talks`, `research`, and ten
  `research-*` project pages.
- **Maps and enriched home responses** — `map.json` and `home.json` in each
  directory retain route-discovery evidence.

There are 27 page Markdown files and 327 inline Markdown image references. The
`/home` alias is kept because it is a linked route, even though it renders the
same content as the site root.
