# DIAL candidate Team, Project, and Research Theme records from public captures

> **Status:** operator-facing candidate data, not approved copy. This file maps
> public claims to the current Payload field names in `src/collections/Team`,
> `Projects`, and `ResearchThemes`. It deliberately does not add facts that are
> not in a capture. Record IDs, Media IDs, relationship IDs, `slug`, `name`, and
> rich-text Lexical JSON must be assigned during import.
>
> **Source:** the 2026-09-12 Firecrawl capture in `../scraped-data/`
> (`nsu-hci-current-website/`, `nova-ahmed-personal-site/`) plus the unchanged
> `DIAL Proposal.md`. Line numbers refer to those files as captured.
>
> **Scope note:** the captured NSUHCI site combines the wider NSUHCI community,
> BanglaCHI, and DIAL. A listed individual or event is therefore not proof that
> it should be a public DIAL record. The current site also calls DIAL a 50+
> person lab, while the proposal contains an older roster. Treat the page
> section and wording as evidence of the proposed `role`, not a present-tense
> membership assertion.

## Field mapping rules

| Source material                                                             | Canonical field(s)                                                                                | Handling                                                                                                                                                                    |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Display name                                                                | `firstName`, `middleName`, `lastName`, generated `name`, generated `slug`                         | Split only when the source makes the parts clear. Preserve initials (for example `F. M. Abir Hossain`) rather than guessing expanded names.                                 |
| “Research Assistant, DIAL”                                                  | `title`                                                                                           | Verbatim title. The page subsection may suggest `role` but is not sufficient to distinguish graduate versus undergraduate status.                                           |
| “Former … DIAL” / Study Leave / Professional Leave                          | `role: alumni`, `currentPosition`, optional `email`                                               | `alumniYear` is **not** supplied by these captures. “Former” supports the role; study/professional leave headings remain a conflicting presentation choice for the website. |
| “Researchers Pursuing Ph.D. and Postgraduate Studies” list, grouped by year | candidate `currentPosition` only                                                                  | The year heading is when the person **started** the listed programme (“from Fall 2026 @ …”), not when they left DIAL. Do not copy it into `alumniYear`.                     |
| “Director” / “Member” in proposal                                           | `role: director` / `faculty` / `interdisciplinary-collaborator`                                   | Nova is explicitly Director. The other supervision-table people are only “Member”; their final role needs confirmation.                                                     |
| Headshot immediately before a person                                        | `photo` → Media upload                                                                            | Preserve its direct URL and original caption/proximity. Do not identify people in an uncaptained group photo.                                                               |
| Project title, description, people, funding, publications                   | `title`, `localName`, `abstract`, `content`, `teamMembers`, `grants`, `publications`, `heroImage` | Only connect a relationship when the source names it. Funding must be created/reconciled as a Grant first. Publication matching is a separate bibliographic review.         |
| Proposal’s six bullets                                                      | Research Theme `title`, `shortDescription`                                                        | There is no public description for each individual theme. Do not use project names as substitute themes.                                                                    |

`Projects.status` is not explicitly stated for most historic personal-site work.

`status: ongoing` only where noted. `featured`, `publishedAt`, `pageAuthor`,
SEO fields, `designVersion`, and all join fields are editorial/system choices,
not source data.
