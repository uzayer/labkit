# Where DIAL launch data comes from

| Proposed record or field                                                   | Front Door / capture                                                                       | Field-value source                                                                                     | Review boundary                                                                                                                         |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| DOI-backed Publications                                                    | Nova Ahmed's ORCID, scoped to `since=2017`; then Google Scholar BibTeX for omissions       | Crossref for bibliographic fields; OpenAlex for abstract and open-access details                       | PI or Lab Editor decides which career works belong to DIAL; the year filter is only a first cut.                                        |
| Publications listed on the NSUHCI site                                     | `scraped-data/nsu-hci-current-website/publications.md` (2026-09-12)                        | Citation text is comparison evidence; DOI hydration supplies final fields when possible                | The wider site includes duplicates and misattributions. Never treat its inclusion as automatic DIAL approval.                           |
| Team Members, Projects, News Items, Awards, Grants, Organizations, LabInfo | NSUHCI/DIAL capture, Nova Ahmed personal-site capture, and `scraped-data/DIAL Proposal.md` | Candidate fields in `organized-from-scrapes/` and `dial-test-full-data/`; raw captures remain evidence | NSUHCI, DIAL, and Nova's career are different scopes. A Lab Editor must resolve ownership, current status, role, and public visibility. |
| Research Themes                                                            | Six proposal themes; nine prototype route slugs                                            | The nine route titles and descriptions currently come from prototype editorial work                    | DIAL needs to approve the nine-theme taxonomy before seed.                                                                              |
| Venues and co-author Organizations                                         | DOI hydration                                                                              | Crossref/OpenAlex, with safe identifier matching                                                       | Free-text labels remain when no safe Venue or Organization match exists.                                                                |
| Images                                                                     | Raw captures have image URLs, not owned media files                                        | Lab-provided originals where available                                                                 | Check permission, attribution, and whether the image still resolves before upload.                                                      |

`review-manifest.json` gives the candidate ID and source note for each prototype record. Its notes vary in precision: many name a capture and heading, while ORCID-only Publication notes name an ORCID iD and DOI. The three `organized-from-scrapes/*.md` documents provide line-level citations for the scrape-derived claims. The manifest is an index to those materials, not a claim that every prototype field has independent evidence.

When a Publication is hydrated, Payload's `provenance.source` records whether Crossref or OpenAlex supplied its fields. The ORCID iD and selection file belong to the Import Run: ORCID is the Front Door, not the field-value source. A reviewed manual seed should copy the raw capture reference into `provenance.sourceNote` where the collection supports it; for collections without that field, keep the review manifest and seed report as the durable evidence.
